# 상페닥터 90일 마케팅 계획

기간: **2026년 9월 25일~12월 23일**  
목표: 판매 중인 셀러의 상세페이지 제작·리뉴얼 **유료 계약을 현재 월 0~2건에서 3개월 차 월 3~4건으로 확대**

## 1. 운영 전제와 핵심 메시지

| 항목 | 기준 |
| --- | --- |
| 우선 고객 | 이미 상품을 판매하며 상세페이지의 구매 흐름을 개선하려는 셀러 |
| 평균 계약 금액 | 100만 원 미만 |
| 신규 작업 처리 여력 | 월 6건 이상 |
| 마케팅 운영 시간 | 주 4~8시간 |
| 월 광고 예산 | 50만 원 미만 |
| 현재 주 수주 채널 | 크몽 등 외부 플랫폼 |

**한 줄 소개:** 상세페이지에서 고객이 구매를 망설이는 지점을 찾고, 필요한 범위만 구조·카피·디자인으로 고칩니다.

고객에게 제안하는 첫 행동은 **무료 AI 진단**이다. 제품 URL 또는 이미지를 받아 우선 고칠 부분을 보여주고, 제작이 필요한 고객에게만 상담과 견적을 제안한다. 자동 진단을 사람의 수작업으로 표현하거나 매출 개선을 보장하지 않는다.

## 2. 고객 확보 경로

1. **기존 고객·셀러 인맥:** 개인별로 제품 상황을 언급하며 무료 진단을 소개하거나 적합한 셀러를 추천받는다. 일괄 발송 대신 답장을 나눌 수 있는 수만큼 연락한다. 기존 플랫폼은 해당 채널에서 계속 문의가 있을 때만 소개 문구를 관리한다.
2. **공개 작업물:** [28g 초소형 피코펌프](https://www.wadiz.io/web/campaign/detail/404078)와 [고래꼬리 실버 팔찌](https://www.wadiz.io/web/campaign/detail/408994)를 완성 작업물로 소개한다. 개선 전 문제, 담당 범위, 매출 성과는 자료가 확인되기 전까지 주장하지 않는다.
3. **검색 콘텐츠:** 실제 셀러가 검색할 질문에 주 1편씩 답한다. 첫 주제는 ‘광고 클릭은 있는데 구매가 없을 때’, ‘상세페이지 첫 화면 구성’, ‘부분 수정과 전체 리뉴얼 판단’이다. 각 글은 한 문제와 해결 순서를 설명하고 무료 진단 링크로 끝낸다.
4. **메타 광고:** 인스타그램·페이스북에서 판매 중인 셀러에게 실제 작업물과 무료 진단을 알린다. 광고 2개를 같은 예산으로 비교하고, 진단 완료와 상담까지 확인한다. 메타 광고 계정과 웹사이트 전환 측정 준비가 끝나면 집행한다.

랜딩페이지의 디자인·문구·섹션은 이 문서 작성 범위에 포함하지 않는다. 광고를 시작하기 전에는 현재 노출되는 후기·통계의 증빙 여부와 진단 신청 동작만 점검하고, 수정이 필요하면 변경안을 별도로 검토한다.

## 3. 12주 일정

**첫 주는 유입을 만드는 데 집중한다.** 1일 차에 무료 진단 신청→결과→상담 연결을 직접 확인한다. 2일 차에는 기존 고객·지인 중 실제 셀러에게 소개를 부탁할 수 있는 사람 5~10명을 정하고, 각자에게 맞는 짧은 메시지와 진단 링크를 보낸다. 연락 가능한 사람이 없다면 이미 운영 중인 SNS·블로그에 실제 작업물 1건과 진단 링크를 올린다. 3~5일 차에는 답장을 확인하고 질문에 응대한다. 매일 연락·게시·진단·상담 건수만 기록하며, 7일 차에 어느 경로에서 반응이 왔는지 본다. 공개 게시물에는 허락받은 후기와 확인된 작업 사실만 사용한다.

메타 광고는 진단 신청과 상담이 실제로 작동하고 메타 유입을 구분할 수 있으면 첫 주에도 7일·총 7만 원을 상한으로 시험한다. 준비되지 않았다면 계정·전환 측정부터 설정한다. 검색 글과 검색 등록은 이후에도 계속하되 첫 주 문의를 만드는 유일한 수단으로 기대하지 않는다.

| 기간 | 실행 | 확인할 결과 |
| --- | --- | --- |
| 1~2주 | 메타 광고 계정·전환 측정 확인, 사례 소재 2개 제작, 조건이 맞으면 7만 원 이내 첫 시험; 기존 인맥 소개도 병행 | 광고에서 진단·상담으로 이어지는지 확인 |
| 3~4주 | 검색 글 2~3편 발행, 사이트 검색 등록·색인 확인, 첫 주 유입·상담 기록으로 소개 방식 개선 | 어떤 채널에서 적합 상담이 시작됐는지 구분 가능 |
| 5~8주 | 메타 광고 월 최대 15만~30만 원 범위에서 성과 좋은 소재만 유지, 주 1편 콘텐츠 발행, 주간 문의 품질 확인 | 적합 상담을 만드는 소재와 글 확인 |
| 9~12주 | 성과 좋은 검색어·콘텐츠만 유지, 후기와 작업물 소개 개선, 광고비 월 최대 40만 원까지 조정 | 월 적합 상담 10~12건, 유료 계약 3~4건을 목표로 평가 |

광고는 측정 준비 전에는 집행하지 않는다. **누적 광고비 20만 원을 쓰고도 적합 상담이 0건이면 증액을 멈춘다.** 이때 검색어, 광고 문구, 진단 신청 과정 중 어디에서 고객이 이탈하는지 확인한다.

## 4. 측정과 주간 운영

`유입 채널 → 진단 완료 → 결과 확인 → 상담 → 적합 상담 → 견적 → 계약`을 주 단위로 기록한다. **적합 상담**은 판매 중인 제품, 현재 상세페이지, 개선 의사가 확인된 건으로 정의한다. 첫 4주 수치는 기준선을 만드는 용도이며, 3개월 차 목표는 그 결과를 보고 조정한다.

| 주차 | 유입 채널 | 진단 완료 | 상담 | 적합 상담 | 견적 | 계약 | 광고비 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1주 | 메타 / 콘텐츠 / 소개 |  |  |  |  |  |  |

매주 4~8시간을 **광고 소재·글 제작 2시간, 광고 점검 1시간, 상담 1~3시간, 성과 확인 1시간**에 배분한다. 문의 원본과 고객 자료는 공개 허락 없이 콘텐츠에 사용하지 않는다.

## 5. 바로 사용할 문구

**크몽 소개 초안**  
“광고로 방문은 들어오는데 구매가 적거나, 제품의 장점이 상세페이지에서 잘 전달되지 않나요? 상페닥터는 현재 페이지의 첫 화면, 정보 순서, 신뢰 근거, 구매 안내를 점검합니다. 제품 자료와 작업 범위를 확인한 뒤 문구 수정, 부분 리뉴얼, 전체 제작 중 필요한 작업을 제안합니다.”

**메타 광고 문구 초안 A**

“광고로 방문은 오는데 구매로 이어지지 않나요? 지금 쓰는 상세페이지 URL로 구매를 망설이게 하는 지점을 무료로 확인해보세요.”

**메타 광고 문구 초안 B**

“상세페이지를 전부 새로 만들기 전에, 먼저 어디를 고쳐야 할지 확인하세요. 제품 URL 또는 이미지로 무료 AI 진단을 시작할 수 있습니다.”

광고 문구는 실제 등록할 광고 상품의 글자 수와 심사 기준에 맞춰 줄인다. 후기·성과 수치는 확인 가능한 근거가 있을 때만 사용한다.

## 6. 아직 실행되지 않은 항목

이 파일은 **실행 계획**이다. 메타 광고 초안은 아직 만들지 않았고 광고도 집행하지 않았다. 2026년 9월 28일 메타 픽셀의 `PageView`와 진단 완료 후 `Lead` 전송 로직을 운영 사이트에 배포했다. 운영 사이트 방문 후 `PageView`가 6건에서 10건으로, 새 진단 후 `Lead`가 2건에서 3건으로 늘어난 것을 메타 데이터 세트 개요에서 확인했다. 유료 광고 집행 전에는 상담 기록과 광고 설정을 확인한다. 랜딩페이지는 이 작업에서 변경하지 않았다.
