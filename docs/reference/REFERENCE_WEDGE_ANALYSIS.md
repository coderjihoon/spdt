# Reference Design Analysis

대상 사이트: `https://tough-teammates-817917.framer.app/`  
페이지 타이틀: `Wedge · SaaS Template for Framer`  
분석 일시: `2026-04-28`  
분석 기준 뷰포트:
- Desktop: `1440px` 너비
- Mobile: `390px` 너비

## 1. 한 줄 인상

이 사이트의 핵심 인상은 `밝은 화이트 SaaS 랜딩 + 아주 큰 타이포 + 과하지 않은 보라 포인트 + 둥근 연회색 카드 + 넓은 여백`이다.  
눈에 띄는 건 화려한 장식이 아니라, `정돈된 비율`과 `섹션 사이의 호흡`이다.

중요한 점:
- 카드가 많지만 무겁지 않다.
- 보라색은 메인 브랜딩 포인트로만 제한적으로 사용된다.
- 그림자, 테두리, 글로우가 거의 과장되지 않는다.
- 제품 UI 목업이 실제 “서비스 화면”처럼 보이도록 배치된다.

## 2. 전체 레이아웃 구조

페이지 흐름은 아래 순서다.

1. 상단 얇은 프로모션 바
2. 심플한 헤더 네비게이션
3. 중앙 정렬 Hero
4. 넓은 제품 프리뷰 이미지
5. 로고 마키 / 신뢰 구간
6. 3열 기능 카드
7. 텍스트 + 이미지 교차 섹션 3개
8. 후기 카드 masonry 구간
9. 2열 FAQ
10. 하단 CTA 배너
11. 다단 Footer

레이아웃상 특징:
- 데스크탑 기준 메인 컨테이너는 거의 항상 좌우 `80px` 여백 안에서 정렬된다.
- 주요 섹션 제목은 컨테이너 폭을 거의 꽉 쓰지만, 실제 콘텐츠는 항상 적당히 좁혀 읽기 폭을 유지한다.
- Hero 이후 구간은 `섹션마다 명확한 블록 단위`로 분리되지만, 각 블록이 박스에 과하게 감싸지지는 않는다.
- 페이지 전체가 “큰 캔버스 위에 구성요소를 띄워 놓은 느낌”이다.

## 3. 시각 톤과 분위기

### 3.1 색감

기본 배경은 거의 `순백색`에 가깝다.  
여기에 보라색 계열 포인트와 아주 옅은 회색 카드가 조합된다.

관찰 포인트:
- `body background`: 사실상 흰색
- 본문 기본 텍스트: 거의 검정보다 약간 부드러운 `짙은 네이비/슬레이트`
- 보조 본문: 푸른 기가 도는 회색
- 포인트 컬러: `짙은 인디고/보라`
- 카드 배경: `#f7f7f7` 계열의 아주 연한 회색

인상적으로 보이는 이유:
- 보라색을 전체에 뿌리지 않고 `CTA`, `아이콘`, `하단 배너`, `Hero 주변 글로우` 정도에만 쓴다.
- 중립색의 비율이 높아서 SaaS 특유의 신뢰감이 유지된다.

### 3.2 배경 처리

배경 장식은 많지 않다.

주요 처리:
- Hero 하단에 아주 옅은 보라/블루 광원처럼 보이는 확산형 그라데이션
- 마지막 CTA 배너에만 퍼플 그라데이션 배경
- 그 외 대부분 구간은 깨끗한 흰 배경

즉, 이 사이트는 `배경 자체로 밀어붙이는 디자인`이 아니라 `여백 + 카드 + UI 프리뷰`로 분위기를 만든다.

## 4. 타이포그래피 시스템

Playwright로 확인한 데스크탑 기준 주요 수치:

| 요소 | 크기 | 줄간격 | 굵기 |
|---|---:|---:|---:|
| Hero H1 | `72px` | `72px` | `500` |
| 메인 섹션 H2 | `52px` | `57.2px` | `500` |
| Trust 소제목 | `24px` | `28.8px` | `500` |
| Hero 본문 | `20px` | `30px` | `400` |
| 카드 본문 | `16px` | `24px` | `400` |
| 네비 텍스트 | `12px` | 기본값 | `400` |

모바일 기준:

| 요소 | 크기 | 줄간격 |
|---|---:|---:|
| Hero H1 | `40px` | `40px` |
| Hero 본문 | `17px` | `25.5px` |

타이포 특징:
- Hero는 시각적으로 매우 크지만, 굵기를 `bold`까지 올리지 않고 `500` 수준에서 마감한다.
- 줄간격이 타이트하다. 특히 Hero와 52px급 섹션 제목은 `라인 높이도 낮게` 잡아 덩어리감을 만든다.
- 본문은 읽기 편한 `16/24`, Hero 본문만 `20/30`으로 키운다.
- 네비와 버튼은 생각보다 작다. 큰 제목 대비 컨트롤 UI는 소형으로 눌러 전체가 고급스럽게 보인다.

## 5. 헤더 / 네비게이션 특징

데스크탑 네비 바 측정값:
- 높이: `72px`
- 내부 패딩: `28px 80px`

디자인 특징:
- 흰 배경 위에 별도 큰 박스 없이 아주 가볍게 놓여 있다.
- 로고, 메뉴, 우측 액션으로 단순하게 구성된다.
- 메뉴 텍스트가 작고 얇아서 Hero와 경쟁하지 않는다.
- 우측 `Get started` 버튼만 보라색 배경으로 강조된다.

핵심은 `헤더가 존재감이 강하지 않다`는 점이다.  
랜딩페이지의 주인공은 네비가 아니라 Hero 카피다.

## 6. Hero 섹션 특징

데스크탑 기준 Hero 텍스트 블록:
- H1 폭: `620px`
- H1 위치: 대략 `x 403 / y 240`
- 본문 폭: `620px`

Hero 구성 특징:
- 텍스트는 중앙 정렬 기반이지만, 내부 정보 배치는 매우 정리되어 있다.
- H1, 본문, CTA 2개가 수직으로 떨어진다.
- CTA 아래에 바로 큰 UI 프리뷰가 온다.
- Hero 이미지는 일러스트가 아니라 `제품 인터페이스 카드 조합`에 가깝다.

특히 중요한 포인트:
- Hero 비주얼이 “감성 이미지”가 아니다.
- 제품 프리뷰가 작은 카드 여러 장으로 조합되어, SaaS 제품의 기능과 신뢰를 직접 보여준다.
- 페이지 첫인상은 카피 절반, UI 목업 절반으로 만들어진다.

## 7. 카드 시스템

샘플 카드 측정값:
- 카드 배경: `rgb(247, 247, 247)`
- 반경: `20px`
- 내부 패딩: `40px`
- 그림자: 거의 없음

이 사이트의 카드 특징:
- 테두리보다 `배경 톤 차이`로 카드가 구분된다.
- 그림자에 의존하지 않는다.
- 카드 크기가 넉넉하고 내용도 여유 있게 들어간다.
- 카드 안 요소 정렬이 매우 정돈되어 있다.

결론적으로 이 카드는 `화려한 SaaS 카드`가 아니라 `조용하고 정제된 제품 소개 카드`에 가깝다.

## 8. 섹션별 디자인 특징

### 8.1 Trust / 로고 구간

- 제목은 작은 편인 `24px`
- 로고들은 얇은 흑백 비주얼
- 긴 캐러셀/마키 느낌으로 지나감
- “우리가 대단하다”보다는 “일반적인 SaaS 신뢰 구간”의 톤

### 8.2 3열 기능 카드 구간

- `Wedge is built for you` 대제목 아래 3열 카드 배치
- 카드 크기는 모두 동일
- 각 카드 상단에 작은 보라색 아이콘 1개
- 제목과 본문만으로 구성

여기서 중요한 건:
- 같은 크기의 카드를 반복하지만, 카드 수가 3개로 적어서 지루하지 않다.
- 카드 배경만 옅게 구분하고 과한 보더/그림자를 쓰지 않는다.

### 8.3 교차형 정보 섹션 3개

패턴:
- 왼쪽 텍스트 / 오른쪽 큰 이미지
- 다음 섹션은 반대로 이미지 / 텍스트
- 다시 텍스트 / 이미지

특징:
- 텍스트 영역과 이미지 영역이 거의 `1:1 비율`
- 이미지 박스가 정사각형에 가까워 안정감이 크다
- 섹션 소제목은 보라색의 작은 라벨 역할
- 메인 헤드라인은 `52px`

이 반복 패턴 덕분에 랜딩페이지가 길어도 읽는 리듬이 단조롭지 않다.

### 8.4 후기 구간

- 제목은 크고 강하게 시작
- 본문 카드는 `masonry`처럼 높이가 다르게 배치
- 각 후기 카드는 회색 박스 + 프로필 정보 구조

느낌상:
- 대형 브랜드 레퍼런스보다 “스타트업 템플릿 특유의 구조화된 후기 구간”
- 정보량이 많지만 카드 배경이 가벼워서 답답하지 않다

### 8.5 FAQ 구간

구조:
- 좌측: 큰 제목 + 설명
- 우측: 질문 리스트

특징:
- FAQ를 전체 폭 중앙 정렬이 아니라 `2열 분리`로 처리해 고급스럽다.
- 질문 아이템들도 전체 박스보다는 가는 구분선/얕은 카드 느낌으로 배치된다.
- 이 시점까지 시각적 무게를 많이 올리지 않아, 페이지 후반부도 지치지 않는다.

### 8.6 Final CTA

샘플 측정값:
- 배경색: `rgb(70, 63, 166)` 계열
- 반경: `20px`
- 내부 패딩: `112px`
- 전체 폭: `1265px`
- 높이: `336px`

특징:
- 페이지 전체에서 가장 강한 컬러 블록
- 앞선 모든 흰 배경 구간과 확실히 대비된다
- CTA 버튼은 오른쪽에 정렬되어 “즉시 행동” 포인트를 만든다
- 배경 안에도 약간의 패턴/광원 이미지가 들어가 단조롭지 않다

## 9. 인터랙션 / 버튼 스타일

버튼 특징:
- Primary 버튼은 보라색 배경
- Secondary 버튼은 연회색 배경
- 버튼 높이는 크지 않고, 텍스트도 작다
- 모서리는 `10px ~ 12px` 수준의 적당한 둥글기

중요한 점:
- 버튼이 둥글긴 하지만 과장된 pill 과잉 스타일이 아니다.
- 클릭 요소는 명확하지만, UI가 전반적으로 소리를 지르지 않는다.

## 10. 여백과 리듬

이 사이트를 비슷하게 만들려면 가장 먼저 따라야 하는 건 색이 아니라 `여백 비율`이다.

관찰 포인트:
- Hero 위아래 공간이 크다.
- 섹션 제목과 본문 사이 간격이 넉넉하다.
- 각 블록 사이 간격이 크게 잡혀 있어서 페이지가 길어도 숨이 찬 느낌이 없다.
- 카드 내부 패딩도 작지 않다. 대부분 `40px` 정도로 보인다.

즉, 이 사이트는 밀도 높은 정보형 랜딩이 아니라 `넓은 호흡으로 설득하는 SaaS 템플릿`이다.

## 11. 모바일 대응 특징

모바일에서 확인된 특징:
- Hero H1이 `72px -> 40px`로 축소된다.
- 기능 카드와 후기 카드는 1열 스택으로 내려간다.
- 교차형 정보 섹션은 세로 흐름으로 풀린다.
- 로고 구간은 폭이 좁아지며 띠 형태로 보인다.
- CTA와 FAQ도 단일 열 중심으로 정리된다.

모바일에서도 유지되는 핵심:
- 큰 제목
- 둥근 카드
- 흰 배경 + 보라 포인트
- UI 목업 중심의 시각 체계

즉, 단순히 축소하는 반응형이 아니라 `같은 브랜드 무드를 유지한 채 블록을 세로로 정렬`하는 방식이다.

## 12. 이 레퍼런스를 구현할 때 반드시 기억할 포인트

### 꼭 가져가야 할 것

- 화이트 중심의 아주 밝은 캔버스
- 보라 포인트의 제한적 사용
- Hero의 큰 타이포와 정리된 CTA
- 옅은 회색 대형 카드
- 20px 전후의 안정적인 라운드
- 40px 안팎의 카드 내부 여백
- 52px급 섹션 타이틀
- 교차형 이미지/텍스트 섹션 리듬
- 마지막에만 강한 컬러 CTA 블록 사용

### 가져오면 안 되는 방식

- 카드마다 강한 그림자 넣기
- 베이지/오렌지/웜톤으로 분위기 바꾸기
- 모든 섹션을 큰 박스 안에 또 넣는 중첩 카드 구조
- 너무 굵은 타이포와 과도한 장식 요소 사용
- Hero를 감성 배경 이미지 중심으로 바꾸기

## 13. 우리 상세페이지 제작 서비스로 번역할 때의 해석 가이드

이 레퍼런스를 상세페이지 제작 서비스 사이트로 옮긴다면, 핵심은 아래처럼 번역해야 한다.

- SaaS 제품 UI 목업 -> `상세페이지 프리뷰 카드 / 구조 기획 카드 / 카피 흐름 카드`
- 기능 카드 3개 -> `문제 정의 / 구매 흐름 / 설계 방식`
- 교차형 섹션 -> `분석`, `구조 기획`, `카피 + 디자인` 소개
- 후기 masonry -> `실제 프로젝트 전후 변화`나 `고객 후기`
- 하단 CTA 배너 -> `무료 진단 문의`

중요:
- 레퍼런스의 본질은 “차가운 미니멀”이 아니라 `정제된 SaaS 신뢰감`이다.
- 따라서 우리 쪽 구현도 “따뜻한 감성 브랜딩”보다 `차분하고 구조적인 설득력`이 우선이어야 한다.

## 14. 요약

이 레퍼런스의 본질은 다음 6가지로 요약된다.

1. `화이트 중심의 미니멀 SaaS 랜딩`
2. `큰 제목과 작은 UI의 대비`
3. `보라 포인트의 절제된 사용`
4. `옅은 회색, 큰 반경, 넓은 패딩의 카드 시스템`
5. `교차형 콘텐츠 리듬과 넉넉한 여백`
6. `제품 UI 프리뷰를 중심으로 신뢰를 만드는 구조`

이 문서를 기준으로 후속 구현 시 “겉모양”보다 아래 항목이 맞는지 먼저 확인하는 것이 좋다.

- 색 비율이 화이트 중심인가
- Hero가 충분히 크고 비어 있는가
- 카드가 무겁지 않은가
- 섹션 사이 호흡이 넉넉한가
- CTA만 강하게 강조되는가
- 전체가 감성 사이트가 아니라 SaaS형 신뢰 랜딩처럼 보이는가
