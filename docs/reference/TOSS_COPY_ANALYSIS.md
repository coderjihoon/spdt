# 토스 홈페이지 문구 분석과 상페닥터 적용 방향

분석일: 2026-10-02

## 분석 기준

저장된 다음 텍스트와 현재 상페닥터 홈페이지 코드를 기준으로 분석했다. 토스 사이트의 최신 문구나 실제 화면 배치를 확인한 분석은 아니다.

- `toss-home.txt`: 토스 홈페이지
- `tossinvest-home.txt`: 토스증권 홈페이지
- `tosspayments-home.txt`: 토스페이먼츠 홈페이지
- 현재 홈페이지: `app/page.tsx`, `components/apply/`, `data/apply.ts`

수집된 텍스트의 반복된 글자, 잘린 단어, 과도한 줄바꿈은 문체 특징에서 제외했다. 아래 변경 문구는 적용 제안이며, 홈페이지 코드에는 반영하지 않았다.

## 1. 세 사이트의 문체와 설득 방식

공통점은 고객이 해야 할 일과 얻게 될 결과를 쉽게 보여준다는 것이다. 친근한 해요체를 사용하지만, 서비스마다 강조하는 결과는 다르다.

| 사이트 | 문구의 중심 | 대표 문구 | 상페닥터에 적용할 점 |
|---|---|---|---|
| 토스 | 일상의 번거로움 줄이기 | “몇 번만 누르면 끝나는 송금” | 신청 과정의 간단함 |
| 토스증권 | 어려운 일에 참여할 자신감 | “투자의 힘을 모두에게” | 고객이 개선 방향을 이해하고 실행할 수 있다는 자신감 |
| 토스페이먼츠 | 사업 운영의 부담과 시간 줄이기 | “개발자 없이 운영하는 결제 관리” | 사업자의 실제 고민과 구체적인 해결 결과 |

토스는 ‘알아서’, ‘자동으로’, ‘한 번에’처럼 수고를 덜어주는 표현을 자주 사용한다. 토스증권은 ‘모두’, ‘누구나’, ‘같은 경험’으로 접근성을 강조한다. 토스페이먼츠는 개발자, 연동, 운영, 정산 등 실제 업무를 이름 붙이고 부담이 어떻게 줄어드는지 설명한다.

상페닥터에는 토스페이먼츠의 구체적인 사업자 언어와 토스의 간결한 설명 방식이 잘 맞는다. ‘무엇을 고쳐야 하는지 알게 된다’는 진단의 실용적인 결과를 앞에 둔다.

## 2. 문구를 만드는 방식

### 제목은 결과, 본문은 방법

토스는 제목에서 송금이 간단해진다는 결과를 말하고, 본문에서 연락처와 금액만 입력하는 과정을 설명한다.

- 제목: 고객에게 무엇이 쉬워지는가.
- 본문: 고객이 무엇을 하면 서비스가 무엇을 해주는가.

현재 상페닥터의 ‘상세페이지를 분석해 매출을 올립니다’는 무료 진단 이후의 매출 상승까지 약속한다. 무료 진단에서 바로 제공할 수 있는 결과를 먼저 설명하는 편이 명확하다.

추천 제목:

> 내 상세페이지,\
> 어디부터 고칠지 알려드려요.

추천 설명:

> 판매 페이지 주소나 이미지를 보내주세요.\
> 구매를 망설리게 할 수 있는 부분과 먼저 고칠 3가지를 정리해드려요.

### 추상적인 장점을 행동으로 설명

토스는 ‘쉽다’를 연락처와 금액 입력으로, ‘자동’을 금액과 기간 설정으로, ‘운영이 편하다’를 어드민에서 직접 설정하는 행동으로 풀어낸다.

| 추상적인 표현 | 상페닥터 적용 예시 |
|---|---|
| 상세페이지 개선 방향 제공 | 먼저 고칠 3가지를 알려드려요 |
| 카피 설득력 분석 | 제품의 장점이 구매 이유로 전달되는지 살펴봐요 |
| 모바일 가독성 진단 | 휴대폰에서 글자가 작거나 읽기 어려운 부분을 찾아요 |
| 정보 구조 최적화 | 제품 설명과 후기, 가격이 어떤 순서로 보이는지 살펴봐요 |

### 문장의 역할에 맞춰 말투 사용

| 역할 | 표현 방식 | 목적 |
|---|---|---|
| 제목 | 짧은 결과 또는 핵심 구절 | 핵심을 빠르게 전달 |
| 기능 설명 | ‘살펴봐요’, ‘확인해요’ | 서비스 범위 설명 |
| 결과 전달 | ‘알려드려요’, ‘정리해드려요’ | 제공하는 결과 설명 |
| 신청 안내 | ‘보내주세요’ | 다음 행동 안내 |
| 버튼 | ‘무료 진단받기’, ‘진단서 예시 보기’ | 클릭 목적 전달 |

현재 홈페이지는 ‘봅니다’, ‘확인합니다’, ‘살펴봅니다’가 반복되어 검사 과정에 설명이 집중된다. 설명·결과·행동 요청을 나누면 자연스럽다. ‘드려요’는 결과를 제공하는 문장에 사용한다.

### 고객이 느끼는 부담을 구체적으로 줄이기

토스의 ‘공부할 필요 없이’, ‘신경 쓰지 않아도’, ‘개발자 없이’는 고객이 부담스러워하는 일을 짚는다.

상페닥터가 줄여줄 수 있는 부담:

- 무엇부터 고칠지 판단하는 부담.
- 자료를 완벽하게 준비해야 한다는 부담.
- 무료 진단 후 제작까지 맡겨야 한다는 부담.

추천 문구:

> 진단만 받아도 괜찮아요.\
> 제작을 맡기지 않아도 진단 결과를 받아볼 수 있어요.

신청 화면이 URL과 이미지를 받는 구조라면 ‘자료가 없어도 가능해요’처럼 실제 입력 조건보다 넓은 약속은 피한다.

## 3. 현재 홈페이지의 개선점

### 같은 표현의 반복

‘고객이 어디서 멈추는지’가 첫 화면, 문제 소개, 진단 설명, 진행 과정, 신뢰 섹션에 반복된다. 핵심 관점은 드러나지만 섹션마다 새로 알게 되는 정보가 적다.

섹션마다 서로 다른 질문에 답하도록 제목을 나눈다.

| 위치 | 추천 문구 | 답하는 질문 |
|---|---|---|
| 첫 화면 | 내 상세페이지, 어디부터 고칠지 알려드려요 | 무엇을 받을까? |
| 문제 소개 | 광고는 보는데, 구매로 이어지지 않나요? | 내 고민에도 해당할까? |
| 진단 항목 | 첫 화면부터 구매 버튼까지 살펴봐요 | 무엇을 확인할까? |
| 결과 예시 | 고칠 부분과 이유를 함께 알려드려요 | 결과가 얼마나 구체적일까? |
| 진행 과정 | 주소나 이미지만 보내주세요 | 어떻게 신청할까? |
| 부담 해소 | 진단만 받아도 괜찮아요 | 제작까지 맡겨야 할까? |

### 분석으로 알 수 있는 범위에 맞춘 표현

페이지 분석만으로 ‘고객이 멈추는 곳’을 말하면 실제 이탈 위치를 관측한 것으로 이해될 수 있다. 행동 데이터가 없다면 ‘구매를 망설릴 만한 부분’처럼 분석 범위를 정확히 표현한다.

진단서 예시의 ‘고객이 이탈하고 있어요’ 같은 확정 표현도 실제 행동 데이터가 있는지에 맞춰 검토한다.

### 전문 용어를 고객의 말로 설명

| 현재 표현 | 추천 표현 |
|---|---|
| 셀링포인트 | 제품의 구매 이유 |
| 카피 | 제목과 설명 문구 |
| CTA | 구매·신청 버튼 |
| 첫 화면 후킹 | 첫 화면에서 관심을 끄는 문구 |
| 공신력 근거 | 후기와 인증 |
| 전환 | 구매 또는 신청 |

필요한 전문 용어는 진단서에서 병기할 수 있다. 홈페이지 첫 화면과 일반 설명은 방문자가 바로 이해할 수 있는 말로 쓴다.

### 숫자와 후기는 실제 근거로 확정

현재 `data/site.ts`의 고객 후기 중 10개가 `CustomerReviewsSection`에 노출된다. 실적 수치는 근거를 확인한 뒤 신뢰 근거로 사용한다. AI 학습 데이터 건수 같은 다른 수치도 공개 문구로 사용할 때 근거를 확인한다.

## 4. 적용 범위와 우선순위

제목·설명·버튼·신청 안내 대부분에 적용할 수 있다. 다만 이는 적용 가능한 문구 영역에 대한 판단이며, 전환율 개선을 측정한 결과는 아니다.

| 우선순위 | 적용 대상 | 변경 방향 |
|---|---|---|
| 1 | 첫 화면 제목과 설명 | 무료 진단에서 얻는 결과와 신청 방법을 명확히 전달 |
| 2 | 반복되는 섹션 제목 | 진단 범위·받는 결과·신청 방법을 각각 설명 |
| 3 | 진단 항목의 전문 용어 | 고객이 바로 이해할 수 있는 말로 변경 |
| 4 | 신청 안내와 부담 해소 | 필요한 자료와 제작 의무가 없다는 점을 구체적으로 전달 |
| 5 | 버튼과 상태 안내 | 행동과 진행 상황을 간결하고 일관되게 표현 |

‘먼저 고쳐야 할 3가지’, ‘무료 진단’, ‘진단서 예시 보기’는 이미 이 방향에 잘 맞는다. 이 문구들을 중심으로 나머지를 정리한다.

디자인을 크게 바꾸지 않아도 첫 화면, 섹션 제목, 전문 용어를 먼저 정리하면 서비스의 설명을 더 명확하게 만들 수 있다.

## 5. 홈페이지 작성 기준

- 제목에는 고객이 얻는 결과 하나를 담는다.
- 본문에는 신청 조건과 제공 내용을 구체적으로 쓴다.
- 한 문장에는 한 가지 설명을 담는다.
- 버튼에는 클릭 후 하게 될 행동을 쓴다.
- 일반 설명은 차분한 해요체로 통일하고 문장 역할에 맞춰 종결어미를 선택한다.
- ‘모두’, ‘알아서’, ‘완벽하게’는 실제 제공 범위에 맞춰 사용한다.
- 매출 상승이나 고객 이탈을 관측한 것으로 오해할 수 있는 약속은 근거와 분석 범위에 맞춘다.
- 숫자와 후기는 확인된 자료를 사용한다.

권장 문체: 사업자의 고민을 짚고, 고칠 부분을 쉽게 알려주는 차분한 해요체.

중심 문구: **내 상세페이지, 어디부터 고칠지 알려드려요.**
