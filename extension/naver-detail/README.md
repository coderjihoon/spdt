# 스마트스토어 운영자 자동 수집

운영자 Chrome에 이 폴더를 개발자 모드로 한 번 설치하고, 확장 프로그램 설정에서 서비스 HTTPS 주소와 서버의 `NAVER_WORKER_TOKEN`을 입력합니다. Chrome을 실행하고 네이버 로그인을 유지해야 합니다. 확장 프로그램은 1분마다 작업을 가져와 별도 탭에서 상세정보를 펼치고 본문 텍스트와 이미지 URL을 화면 순서대로 전송합니다. 고객은 상품 URL만 제출합니다.

서버에는 네이버 쿠키·비밀번호·세션을 보내지 않습니다. 작업 토큰은 Chrome 확장 프로그램의 로컬 저장소에 남으므로 운영자 Chrome 프로필 접근을 제한하고, 유출 시 서버 토큰을 교체하세요. 토큰은 32자 이상의 무작위 값으로 설정합니다. 서버는 이미지 주소를 네이버 CDN(`pstatic.net`, `naver.net` 하위 도메인 포함)으로 제한하고, 외부 링크 배너는 진단 엔진에 별도로 알려줍니다. 다른 이미지 호스트를 쓰는 판매자의 이미지는 건너뛰며, 텍스트가 있으면 그 텍스트로 진단합니다.

배포 전 `20261004000000_naver_jobs.sql` 마이그레이션을 적용하고 서버 환경 변수 `NAVER_WORKER_TOKEN`을 설정하세요. 운영자 Chrome이 꺼져 있거나 최근 3분 동안 서버와 연결되지 않았으면 새 신청을 받지 않습니다. 수집 중 연결이 끊기면 작업은 대기하다가 30분 후 실패 처리됩니다. 네이버 보안 확인이 뜨면 실패 처리됩니다. 일시적인 수집 실패는 최대 3회 재시도합니다. 결과를 수신한 뒤 서버가 보고서를 자동 생성하고 이메일을 전송합니다. Chrome 설정 변경 후 확장 프로그램을 다시 로드하세요.

팝업의 수동 확인 버튼은 추출 상태를 점검하는 용도로 남아 있습니다. 실제 운영에는 버튼을 누를 필요가 없습니다.
