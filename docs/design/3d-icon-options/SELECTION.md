# 선택한 방향

- 사용자 선호: C 스타일, 특히 C2 유리 차트.
- 재질과 색: 투명한 유리, 블루·라벤더, 선명한 반사광.
- 크기: C2를 가장 크게 배치하고 보조 오브젝트는 각각 다르게 표시.
- 배치 검토: `hero-c2-preview.html`, `hero-c2-desktop.png`, `hero-c2-mobile.png`.
- 미리보기는 Icons8 공개 이미지와 워터마크를 그대로 사용했으며, 사이트 적용 원본이 아님.
- 실제 적용에 필요한 항목: Icons8 3D Glassy 사용 라이선스와 워터마크 없는 원본, 또는 유사한 스타일의 사용 가능한 무료 에셋.
- 공식 사용 조건: https://icons8.com/illustrations/styles/3d-glassy

로컬 미리보기에서 문구·폼 겹침 및 모바일 가로 넘침이 없음을 확인함.

## 무료 대안 조사

사용자 요청에 따라 Iconora 무료 블루 유리 후보 G1–G8을 `07-free-blue-glass/`에 정리함. 무료 미리보기의 개인·상업적 사용 허용 문구를 공식 사이트에서 확인함. 250–300px 파일이며 고해상도는 유료. G5와 G1을 추천하지만 최종 선택은 아직 하지 않음.
