# 스마트스토어 URL 자동 진단용 수집 서비스 검증 조건

## 필요한 결과

고객은 상품 URL을 신청 화면에 붙여 넣는다. 운영자 개인 컴퓨터가 꺼져 있어도
서버가 판매자가 작성한 상세 본문을 가져오고 진단 보고서를 발행해야 한다.
고객의 네이버 로그인, 확장 프로그램, 이미지 업로드, 상품별 운영자 조작이 없어야 한다.

## 파일럿 입력과 출력

첫 검증 URL: `https://smartstore.naver.com/pizookie/products/7452552588`.
이 한 건은 연결 확인에만 사용한다. 운영 채택은 아래 범위를 모두 통과해야 한다.

- 서로 다른 판매자의 스마트스토어 상품 20건 이상, 브랜드스토어 상품 5건 이상
- 이미지 중심·텍스트 중심·텍스트와 이미지 혼합 상세 본문
- 펼쳐보기 버튼이 있는 상품과 처음부터 전체 본문이 보이는 상품
- 긴 상세 본문, 지연 로딩 이미지, 본문 안의 다른 상품 배너
- 같은 URL의 시간대를 달리한 반복 수집과 여러 고객 신청이 겹친 경우

각 샘플의 실제 판매자 본문을 기준 자료로 확인하고, 수집 결과가 본문 전체를
표시 순서대로 담았는지 비교한다. 단일 URL의 성공률을 전체 스마트스토어의
성공률로 해석하지 않는다.

수집 서비스는 다음 둘 중 하나를 반환해야 한다.

1. 판매자 상세 본문의 텍스트와 원본 이미지 URL을 화면 순서대로 담은 구조화 데이터
2. 위 내용을 서버에서 안정적으로 추출할 수 있는 실제 상세 HTML 또는 본문 API 응답

상품명·가격·대표 이미지·리뷰·판매자 정보만 담긴 상품 메타데이터는 합격이 아니다.
네이버 로그인, 보안 확인, 시스템 오류 HTML도 합격이 아니다.
텍스트만 있는 상세와 본문 속 다른 상품 배너를 구별할 수 있도록 원래 순서를 보존해야 한다.

## 공급자 파일럿에서 확인할 것

- 위 샘플 전체의 상품별 실측 결과와 실패 원인
- 상세 본문 이미지와 텍스트의 누락률, 반환 지연 시간, 실패 코드
- 네이버의 인증 화면/차단 화면을 정상 상품으로 오인하지 않는지
- 요청당 가격, 월 최소 비용, 동시 요청 제한, 재시도 요금
- 상품 URL과 수집 결과의 보관 기간, 로그 정책
- API 장애 시 재시도 가능 조건과 지원 범위

## 서버 연결 기준

위 실측을 통과하면 현재 `collecting` 작업을 서버의 비동기 수집 작업으로 전환한다.
공급자 인증키는 서버 환경 변수에만 저장하고, 임의 URL 접근을 막기 위해 네이버 상품 URL과
이미지 호스트를 검증한다. 수집 성공 시 기존 `processNaverJob`에 순서대로 전달하고,
중복 처리·시간 초과·실패 안내를 검증한다. 일반 쇼핑몰 Cloudflare 캡처는 유지한다.

최종 합격은 운영자 Chrome을 끈 상태에서 위 유형별 실제 URL의 히어로 신청부터
보고서 화면과 이메일 발송까지 확인한 경우에만 선언한다. 네이버의 향후 차단이나
상품별 인증 요구까지 영구히 성공을 보장할 수는 없으므로, 실패 시에는 보고서를
꾸며내지 않고 정확한 상태와 재시도 안내를 제공한다.

## 현재 판단

기존 Browserless·Cloudflare·Apify·Syphoon 시험에서는 피쥬키 상세 본문을 가져오지 못했다.
현재 확장 프로그램 추출기는 `#DEFAULT`를 본문 영역의 기준으로 삼는다.
다른 상세 형식에서 이 선택자가 유지되는지는 확인하지 못했다.
다음 원격 브라우저 후보는 Browser Use Cloud다. 공식 요금 페이지는 월 구독 없이
브라우저 사용 시간과 주거용 프록시 데이터량에 따라 과금하며 가입자 시험 크레딧을
안내한다. 스텔스 브라우저·주거용 프록시·캡차 해결 기능은 문서화되어 있으나,
네이버 스마트스토어 접근 성공은 **아직 실측하지 않았다**. API 키를 확보하면
네이버 로그인 정보를 넣지 않은 한국 출구 브라우저에서 위 샘플의 접속 여부부터
확인한다. 상품별 데이터 사용량과 실제 비용도 기록한다.
DoReq은 네이버 전용 데이터 서비스와 고객별 파일럿을 [문서화](https://doreq.com/naver)하지만,
판매자 상세 본문 API의 제공 여부와 가격은 확인되지 않았다. 파일럿 결과를 받기 전에는
채택하거나 완료로 표시하지 않는다.
