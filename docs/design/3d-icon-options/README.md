# 3D 아이콘 선택 폴더

수집일: 2026-10-07

`index.html`을 브라우저에서 열면 6가지 스타일, 25개 이미지 파일을 비교할 수 있습니다. `overview.png`는 전체 비교표입니다. 파일 ID(A1, C2 등)로 선택하면 됩니다.

## 스타일

| ID | 스타일 | 제공자 | 폴더 | 사용 조건 |
|---|---|---|---|---|
| A | 부드러운 컬러 클레이 | Microsoft Fluent Emoji | [01-fluent-soft](01-fluent-soft/) | MIT · 배포 시 저작권 및 라이선스 고지 유지 |
| B | 선명한 플라스틱 | Icons8 3D Fluency | [02-icons8-fluency](02-icons8-fluency/) | 무료 100px PNG · 실제 사용 시 Icons8 출처 링크 필요. 큰 원본은 별도 라이선스 확인 |
| C | 투명한 유리 | Icons8 3D Glassy | [03-glassy-preview](03-glassy-preview/) | 공개 미리보기 · 선택 검토용. 실제 적용은 유료 구독 라이선스 필요 |
| D | 파스텔 비즈니스 클레이 | River Visual / Pixelbuddha | [04-clay-business-preview](04-clay-business-preview/) | 공개 팩 미리보기 · 선택 검토용. 실제 PNG 원본은 구매/멤버십 라이선스 필요 |
| E | 컬러 그라데이션 | 3dicons V1 | [05-gradient](05-gradient/) | V1 CC0 · 개인 및 상업 프로젝트 사용 가능 |
| F | 다크 메탈 & 골드 | 3dicons V1 | [06-metallic](06-metallic/) | V1 CC0 · 개인 및 상업 프로젝트 사용 가능 |

C·D는 공개 미리보기이며 실제 사이트에 적용할 원본이 아닙니다. 특히 D는 아이콘 팩의 소개 이미지입니다. B는 무료 PNG 해상도가 100px이므로 큰 히어로 아이콘으로 선택하면 고해상도 사용 조건을 확인해야 합니다.
